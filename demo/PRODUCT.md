# Product

## Register

product

## Users

JavaScript and TypeScript developers evaluating state-machine-driven agents. They use the demo to run an agent and understand its conversation and machine state together.

## Product Purpose

Make bounded agent behavior concrete: show the live chat beside the state machine that controls it, with examples that can be run and inspected quickly.

## Brand Personality

Precise, restrained, developer-focused. The interface should feel trustworthy and direct while leaving the machine behavior as the main event.

## Anti-references

Avoid bespoke chat chrome, decorative gradients, oversized controls, excessive rounding, and treatments that drift from assistant-ui defaults.

## Design Principles

- Show the controlling machine and agent output as one system.
- Prefer familiar product patterns over ornamental UI.
- Keep interaction state obvious and controls close to their effect.
- Preserve density without sacrificing legibility.

## Accessibility & Inclusion

Target WCAG AA contrast, complete keyboard operation, visible focus states, semantic status announcements, and reduced-motion support.
