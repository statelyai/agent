The agent skills no longer ship in the package. `graph-engineering`, `loop-to-machine`, `build-machine`, `generate-machine`, `add-traces`, `add-evals`, and `improve-machine` moved to the `stately-agent` plugin in [statelyai/skills](https://github.com/statelyai/skills). Install them with `/plugin install stately-agent@stately` in Claude Code, or `npx skills add statelyai/skills`.
